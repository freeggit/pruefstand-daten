# Prüfstand Daten — Quellenscout

Dieser Zweig sammelt neue, saubere, öffentlich zugängliche Tagesreihen für das Forschungsprogramm «Börsenvorteil / Prüfstand» von Reto Fritschi. Ein automatisierter Quellenscout prüft laufend Kandidatenquellen gegen feste Aufnahmekriterien (täglich, lange Historie, offen, punktgenau, laufend fortgeschrieben, neu, klein genug), zieht bei Erfolg die gesamte Historie ab und schreibt sie nach `data/neu/<id>/<reihe>.csv.gz`. `katalog.json` führt Buch über alle je geprüften Quellen (aktiv, abgelehnt, fehlerhaft, Kandidat), `run_all.py` frischt den Bestand aller aktiven Quellen auf und baut `data/neu/manifest_neu.json`, das die nachgelagerte Suchmaschine liest. Dieser Zweig wertet keine Daten gegen Kurse oder Renditen aus — das ist Aufgabe eines anderen Suchlaufs.
