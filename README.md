Dieser Zweig ist die Lernschleife des Forschungsprogramms «Börsenvorteil / Prüfstand» von Reto Fritschi. Die Suchläufe (`suche/S<Nummer>.json` mit Log und Überlebenden-Liste, `hypothesen.txt.gz`) entstehen seit Verfassung V3.4 automatisch über die GitHub Action «Prüfstand Suche» auf `main`; die Lernrunde (dieser Zweig) wertet sie aus, schreibt `lernberichte/<Datum>.md`/`.json`, steuert den Quellenscout im Zweig `claude/daten-neu` und schlägt Änderungen an Filtern, Regeln oder Verfassung nur vor, ohne sie selbst umzusetzen. `index.json` hält den laufenden Stand (kumulierte Kandidatenzahl, Suchläufe, zuletzt geprüfte Indikatorreihen, Lernberichte).
